# ⏱️ Stopwatch Timer

A simple and interactive **Stopwatch Timer** built using **HTML, CSS, and JavaScript**.  
The stopwatch allows users to start, pause, and reset the timer with a clean and user-friendly interface.

## Features

-  **Start** the stopwatch
-  **Pause** the stopwatch
-  **Reset** the stopwatch
-  Displays elapsed time in real time
-  Simple and responsive user interface
-  Works directly in a web browser

## Technologies Used

- **HTML** – Structure of the stopwatch
- **CSS** – Styling and layout
- **JavaScript** – Stopwatch functionality and timer logic

##  Project Structure

```text
Stopwatch/
│
├── index.html
├── style.css
└── script.js
```

##  How to Run

1. Clone the repository:

```bash
git clone <repository-url>
```

2. Open the project folder.
3. Open `index.html` in any modern web browser.
4. Use the **Start**, **Pause**, and **Reset** buttons to control the stopwatch.
